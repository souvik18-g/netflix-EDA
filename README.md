# Netflix EDA Project #

## Day 70 - Dataset Exploration #

This project explores the Netflix Movies and TV Shows dataset from Kaggle using Python. The goal is to understand the dataset before cleaning, analyzing, and visualizing the data.

## Dataset Source ##

- **Dataset:** Netflix Movies and TV Shows
- **Source:** Kaggle
- **Author:** Shivam Bansal
- **Link:** https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Exploration Tasks

- Loaded the dataset.
- Viewed the first 10 rows.
- Checked the dataset shape.
- Examined column names.
- Reviewed data types using ".info()".
- Viewed summary statistics using ".describe()".
- Checked for missing values.
- Checked for duplicate rows.
- Viewed the first 10 rows of country column.

## Analysis Questions

1. Which country has the highest number of Netflix titles?
2. Which release year has the most Netflix titles?
3. Are Movies or TV Shows more common on Netflix?
4. Which content rating appears most frequently?
5. Which director has directed the highest number of Netflix titles?
